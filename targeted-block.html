单中心模式：按上方所选圆心，核心一组，核心以外按 东北/东南/西南/西北 ×（近郊/远郊）分组。
三中心模式：每个圈划给最近的中心（Thái Hà / Xã Đàn / Bà Triệu），再按 核心/近郊/远郊 分档，共9组；三中心相距仅1–3km，建议把核心半径调小到2–3km。

坐标检索
会按当前半径、分区模式和手动调整结果判断。
也可以直接粘贴 Google Ads 的 Location 字符串，例如 (3km:21.011500:105.849600)。
导入方法：Google Ads Editor → Keywords & Targeting → Locations → Make multiple changes → 勾选 “My data includes columns for campaigns…” → 粘贴某区的 Campaign+Location 两列 → Process。屏蔽圈请改在 Negative locations（排除位置）里添加同一坐标串。
注意：每个广告系列最多 500 个位置定位。
